# Signal — recursos para implementación

Tres diseños independientes, cada uno en SVG vectorial y PNG transparente:

- `logo-completo`: logo, nombre y eslogan.
- `logo-horizontal`: logo y nombre, recomendado para navbar.
- `simbolo-signal`: icono reutilizable.

Todos tienen fondo transparente y están optimizados para interfaces oscuras. El SVG usa tipografía de sistema (Arial/DejaVu Sans), por lo que puede variar ligeramente según el entorno. Son reconstrucciones vectoriales del concepto visual, no trazados exactos de la imagen generada.

En React: `<img src="/assets/signal/logo-horizontal.svg" alt="Signal" />`

Colores: #E247F4, #8555F7, #08C9F4, #C4B5FD.
